## 学习目标

- 说出光合作用的原料、产物与总反应式
- 理解光反应与碳反应（暗反应）的场所与联系
- 举例说明 C₃、C₄ 与 CAM 植物碳同化的差异

## 3.1 光合作用的概览

光合作用是绿色植物、藻类和部分细菌利用光能，把二氧化碳和水合成有机物并释放氧气的过程。

总反应式（以葡萄糖计）：

`6CO₂ + 6H₂O —光能→ C₆H₁₂O₆ + 6O₂`

关键要素：

- **原料**：二氧化碳、水
- **产物**：碳水化合物（储能）、氧气（副产物）
- **能量来源**：光能（主要被叶绿素吸收）
- **场所**：叶绿体（真核生物）

## 3.2 光反应

光反应在叶绿体的**类囊体膜**上进行，包括两个光系统（PS II 与 PS I）。

要点：

1. 光解水释放氧气、质子和电子
2. 电子传递链建立跨膜质子梯度
3. ATP 合酶利用梯度合成 ATP；同时还原 NADP⁺ 为 NADPH

产物：**ATP 与 NADPH**（同化力），副产物氧气。

## 3.3 碳同化（卡尔文循环）

碳同化在叶绿体**基质**中进行，不直接需要光，但依赖光反应提供的 ATP 与 NADPH。

三个阶段：

1. **羧化**：RuBisCO 催化 CO₂ 与 RuBP 结合（固定）
2. **还原**：消耗 ATP 与 NADPH，生成三碳糖（G3P）
3. **再生**：部分 G3P 再生 RuBP，循环继续

每固定 3 个 CO₂，净产出 1 个 G3P。

## 3.5 光呼吸与 CAM 途径

**光呼吸**是 RuBisCO 加氧反应引发的耗能过程：RuBP 与 O₂ 结合生成 3-磷酸甘油酸和 2-磷酸乙醇酸，后者经乙醇酸途径回收碳骨架，消耗 ATP 与还原力而不净产糖。

**CAM 植物**（景天酸代谢植物）夜间开放气孔，由 PEP 羧化酶固定 CO₂ 为苹果酸储存于液泡；日间关闭气孔，脱羧释放 CO₂ 供卡尔文循环使用，从而在干旱环境中兼顾碳同化与水分保持。

## 小结

光反应把光能转化为化学能（ATP、NADPH），碳同化把化学能存入有机物。二者场所不同、产物互补；光呼吸是碳同化的竞争旁路，CAM 途径是干旱适应的碳同化时空调节策略。
